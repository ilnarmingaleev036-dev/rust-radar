# RUSTRADAR

Мониторинг Rust-серверов: онлайн и вайпы. Node.js 22+, без зависимостей.

## Локальный запуск
    node server.js        # http://127.0.0.1:3000

## Переменные окружения
- STEAM_API_KEY — ключ Steam Web API (бесплатно: steamcommunity.com/dev/apikey), обязателен
- PORT — порт (хостинг обычно задаёт сам)
- HOST — 127.0.0.1 локально, 0.0.0.0 на хостинге
- TRUST_PROXY=1 — если сайт стоит за прокси хостинга (нужно для лимитов по IP и редиректа на HTTPS)
- TRUST_PROXY_HOPS — сколько прокси стоит перед сайтом (по умолчанию 1). Если лимит срабатывает у всех сразу, поставь 2

## Деплой на Render (бесплатно)
1. Создай репозиторий на GitHub и залей туда содержимое этой папки.
2. render.com -> New -> Blueprint (или Web Service) -> выбери репозиторий.
3. Render сам прочитает render.yaml. Нажми Deploy.
4. Через пару минут сайт будет на https://rustradar.onrender.com (адрес покажет Render).

Бесплатный план засыпает после простоя, первый заход после паузы грузится дольше.
